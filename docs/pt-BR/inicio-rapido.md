# Início rápido

Valide o profile, confirme a instalação compatível e escolha o adaptador. Use
região plugin para ciclo independente; Dynamic Content para a mesma narrativa
de KPIs/tabelas; modo misto quando ambos forem necessários. Mantenha SQL,
métricas, binds e autorização na package de domínio e carregue o runtime uma vez
por página. Consulte os exemplos sintéticos em `examples/`.
