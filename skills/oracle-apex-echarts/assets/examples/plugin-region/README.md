# Plug-in region example

Create a region of type **Apache ECharts for Oracle APEX**, assign a stable
Static ID, keep Mode `CHART`, select `NORMALIZED_SQL` or `OPTION_JSON`, and paste
the matching synthetic query. Use `INLINE` first; choose `AJAX` when the region
has independent filters, refresh, latency, or payload. Configure server-side
authorization, Items to Submit, accessible description, empty text, and a safe
error. The neutral profile defaults to bars and disables download.
